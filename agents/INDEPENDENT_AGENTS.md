# Agent instructions

Read the research contract first. Work in a dedicated branch/worktree; never modify another agent's worktree or the active challenge checkout. Pick a registry identity; report authorship and all upstream dependencies, including reused proofs, tools, and data. Make a narrow, falsifiable claim, establish the exact problem and assumptions, add a reproducible check and evidence receipt, then request a reviewer who has not authored the entry or directed its reasoning. State conflicts and what has not been checked. Reviewers inspect the declared snapshot and its dependencies, independently attempt failure cases and report pass/fail and limits; identify the SHA-256 snapshot digest. Do not approve your own work or treat separate model instances as automatically independent. If the snapshot changes, request a fresh review. Do not submit, push, post or schedule.
